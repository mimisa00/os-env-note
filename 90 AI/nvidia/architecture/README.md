# NVIDIA GPU 架構世代對照表

| 架構世代 | 發表年份 | 代表顯卡 | 定位 |
|---|---|---|---|
| Turing | 2018 | RTX 2080 / 2080 Ti（消費級）<br>Quadro RTX 系列（工作站）<br>Tesla T4（資料中心，少量） | 以消費級為主,工作站與資料中心版存在但規模較小 |
| Ampere | 2020 | RTX 3060 / 3090（消費級）<br>A100（資料中心） | 消費級 + 資料中心都有,是明確分兩條產品線的起點 |
| Ada Lovelace | 2022 | RTX 40 系（4070 / 4090 等,消費級）<br>RTX 6000 Ada Generation（工作站）<br>L4 / L40 / L40S（資料中心,主打 AI 推論） | 消費級 + 工作站 + 資料中心三者皆有,與 Hopper 同期並行推出（Hopper 主攻訓練,Ada 資料中心版主攻推論） |
| Hopper | 2022 | H100 / H200 | 只有資料中心版,沒有消費級或一般工作站卡,一般人買不到 |
| Blackwell | 2024~2025 | B100 / B200（資料中心）<br>RTX 50 系(5090 / 5080 等,消費級)<br>RTX PRO 6000 Blackwell（工作站） | 資料中心 + 消費級 + 工作站三種產品線齊全 |

## 補充說明

- **Ada Lovelace 不是純消費級架構**:雖然大眾最熟悉的是 RTX 40 系列消費卡,但同一世代也有工作站卡（RTX 6000 Ada）與資料中心卡（L4 / L40 / L40S,主要鎖定 AI 推論與多模態工作負載),因此定位上應與 Blackwell 類似,是「三線產品都有」,只是資料中心版的市場聲量不如 Hopper。
- **Turing 也不是純消費級**:雖然 RTX 2080 系列最知名,但當時也有 Quadro RTX 工作站卡與 Tesla T4 資料中心卡,只是規模與後續世代相比小很多。
- **Hopper 與 Ada Lovelace 是同期架構**:兩者幾乎同時發表(2022 年),分工上 Hopper 專攻資料中心訓練與高階運算,Ada Lovelace 則涵蓋消費級繪圖、工作站與資料中心推論。
- **Blackwell** 是目前唯一一個從一開始就完整規劃「資料中心 + 消費級 + 工作站」三線產品的世代。
